# Route to exactly one specialist

Do small file work yourself; delegate only what needs a toolbox you lack, or is
genuinely large.

- Match the task to one specialist and pick it. **Never fan the same task to two
  to compare** — it doubles cost and forces you to referee two answers.
  - `researcher` — anything on the live web (the only one with general web access).
  - `data-analyst` — documents and data files: PDF/Word/Excel/CSV/JSON/SQLite,
    archives.
  - `media-ops` — audio, video, images: convert, trim, resize, extract, metadata.
  - `coder` — read/run/change code, run tests, write scripts, install pinned deps.
- Ask for a **summary and the file paths it wrote, not a dump** — its full reply
  lands in your context at full price, so tell it to write long output to a file.
- Say plainly when nobody fits, rather than forcing a bad match.
